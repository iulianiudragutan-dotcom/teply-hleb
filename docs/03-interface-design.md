# Интерфейс пекарни и доска настроения

Доска `moodboard.svg` содержит фотографии выпечки, палитру и типографику. Основные цвета интерфейса: фон `#FFFDF9`, текст `#231F1B`, акцент `#A23225`, линии `#DBD3CA`. Заголовки — Arial/Helvetica. Адаптивность настроена на широкие, планшетные и мобильные экраны. В CSS заданы состояния hover/focus/disabled и режим reduced-motion.

| Страница или окно | Содержание | Действия |
|---|---|---|
| Главная | Вступление, каталог, новости, QR-код, проверка статуса | Категории, поиск, корзина, заказ |
| Корзина и оформление | Товары, сумма, имя, телефон, время, способ получения | Количество 1–20, самовывоз или адрес доставки |
| О нас | Описание пекарни, FAQ | Раскрытие ответов |
| Акции | Подборки изделий | Добавление в корзину |
| Новости | Публикации | Поделиться ссылкой |
| Контакты | Филиалы, карта, форма | Выбор филиала, поиск адреса, сообщение |
| Личный кабинет | Вход, регистрация, восстановление, мои заказы | Сохранение корзины в БД, просмотр заказов |
| Панель сотрудника | Заказы, товары, фотографии, персонал, сообщения, отчёт | Вход, редактирование и статусы |

Путь покупателя: найти изделие → добавить в корзину → выбрать получение → указать данные → получить номер → проверить статус. Путь сотрудника: войти → увидеть заказ → назначить ответственного → изменить статус → сформировать отчёт. Для подтверждения этапа проектирования снимки каждого экрана и взаимодействия должны быть помещены в отчёт по проекту.
