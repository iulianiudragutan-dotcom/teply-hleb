# Начало работы с проектом

Сайт «Тёплый хлеб» сопровождается кодом, SQL и учебной документацией по приложениям 1–5.

- `01-domain-analysis.md` — предметная область, аудитория, конкуренты, цели и экономика.
- `02-business-processes.md`, `idef0-*.svg` — процессы и IDEF0.
- `03-interface-design.md`, `moodboard.svg` — дизайн и страницы.
- `04-database-design.md`, `database-*.svg`, `queries.sql` — БД, связи и запросы.
- `05-verification-results.md`, `test-plan.md` — тесты и результаты.
- `06-deployment-and-handover.md` — размещение и передача.
- `../README.md` — установка и сценарии использования.

Рабочую версию проверяют по адресу http://150.241.124.248/. Для новой установки используют `server/schema.sql`; для обновления прежней версии — только `docs/migration_v2.sql`.
