# Визуальное направление

Пекарня оформлена как простая витрина: крупное фото выпечки, чёткий заголовок, спокойный каталог строками и заметные ссылки. В оформлении нет декоративных теней и одинаковых карточек для каждого вида содержимого.

| Элемент | Значение |
|---|---|
| Фон | `#FFFDF9` |
| Тёплая поверхность | `#F4E8DC` |
| Текст | `#231F1B` |
| Акцент | `#A23225` |
| Разделители | `#DBD3CA` |
| Шрифт | Arial, Helvetica, sans-serif |

На главной: шапка с меню, поиском, корзиной и ссылками «Поделиться», первый экран с выбором адреса и предложением, каталог с фильтром, две новости со сменой по кнопкам, самовывоз, статус заказа и раздел для телефона с QR-кодом. На внутренних страницах сохранены те же цвета и типографика. QR-код ведёт на текущий IP-адрес сайта. Кнопка установки веб-версии показывается только при поддержке браузером. Переходы меню, поиска, слайдера и секций короткие; при `prefers-reduced-motion` они отключаются.
