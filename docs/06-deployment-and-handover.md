# Размещение и передача проекта

Рабочий адрес: http://150.241.124.248/. Сервер: Ubuntu 24.04, Caddy, PHP-FPM 8.3, MariaDB. Корень сайта: `/var/www/teply-hleb`.

## Обновление существующего сайта

1. Создать резервную копию файлов и БД.
2. Однократно применить `docs/migration_v2.sql` к действующей БД. Миграция сохраняет существующие заказы и товары, добавляет справочники, личные кабинеты, персонал, доставку и SQL-представления.
3. Скопировать файлы через `scripts/deploy-update.sh /путь/к/teply-hleb`. Скрипт проверяет PHP и не перезаписывает рабочие `server/config.php` и `uploads/`.
4. Проверить ответы страниц, каталог, вход покупателя и сотрудника, заказ, статусы, обратную связь, мобильную ширину 375 px.
5. Сохранить результаты в `docs/05-verification-results.md`.

## Публикация исходников

В репозиторий GitHub помещают код, диаграммы и документацию. Рабочий файл конфигурации с паролем, дамп клиентских данных и загруженные пользователями файлы не публикуют. GitHub Pages поддерживает статические страницы и не выполняет PHP/MySQL; рабочая версия остаётся на PHP-сервере.

## Учебные ограничения

Контакты, ассортимент и фотографии являются демонстрационными. Код восстановления пароля выдаёт сотрудник после проверки личности; автоматическая SMS-рассылка и онлайн-оплата не подключены. Доставка представлена как оформление заказа с адресом и статусом. Настоящая доставка требует реальной операционной службы и уточнения зоны обслуживания.
